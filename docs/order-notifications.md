# Order notification testing
New orders only. COD confirmation is queued at creation; online confirmation at verified capture. Fulfillment events are queued transactionally; cancellation is queued on stock release. Existing orders are not backfilled. OUT_FOR_DELIVERY is manually marked by an administrator (no courier webhook). A unique order/channel/event key prevents repeated event enqueue. Provider acceptance is not proof of delivery. Ambiguous or failed sends go to REVIEW, not automatic retries. No sending in production; test flags are off by default. Enable email with ORDER_EMAIL_TEST_ENABLED=true and ORDER_EMAIL_TEST_RECIPIENT set to your own verified customer email. Restart server with existing SMTP configuration. Links use APP_ORIGIN; localhost links work on the host computer only.
WhatsApp requires the official Meta Cloud API, a registered test recipient in E.164 format including +, access token, phone number ID, supported Graph version and six approved utility templates. Each template must use two positional body text variables: order reference and event details, in that order. Use fixed stage-specific copy including a test disclaimer. The test recipient must opt in at checkout; they can stop updates on the order page. No personal address is sent in WhatsApp. No public tracking URL is available yet; shipping updates include courier and tracking number. Production requires public HTTPS, recipient verification, consent management, approved templates, delivery webhooks, review/retry tooling, and courier integration. Never commit credentials.

## Branded email rendering
All six events use a table-based HTML email with inline styles and a plain-text fallback. The progress indicator reflects the notification event, not a later order state. Current catalog thumbnails from the configured Cloudinary cloud are included when available; images are not historical order snapshots and may be blocked by email clients. No new migration, credentials or packages needed. Existing accepted notices are not resent. Links remain local until public HTTPS deployment. Test recipient restrictions are unchanged.
